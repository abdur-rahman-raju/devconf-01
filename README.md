# 🎤 DevConf 2026

A responsive landing page for a fictional developer conference, built with HTML and CSS as a practice project.

## 🌟 Sections
- Header with navigation and a Register button
- Hero section with the event banner
- Meet the Speakers cards
- Ticket pricing (Standard, Pro, Team)
- AI Networking Match form (UI design)
- Footer

## 🛠️ Technologies Used
- HTML5
- CSS3
- Google Fonts (Inter)

## 🚀 Run Locally
Download or clone the repo and open `index.html` in your browser.

## 📌 Status
Work in progress. Speaker names and event details are sample content for design practice only.
